# RadmehrTrading Pro 1.0.0

نسخه اندروید RadmehrTrading با رابط فارسی و RTL.

## ساخت APK
در GitHub از مسیر Actions → Build RadmehrTrading APK → Run workflow اجرا کنید.
پس از پایان، از بخش Artifacts فایل APK را دریافت کنید.

## وضعیت این سورس
این سورس رابط کاربری و منطق نمایشی تحلیل/سیگنال را دارد. اعداد قیمت و سیگنال‌های موجود در نسخه فعلی نمونه هستند؛ برای تحلیل واقعی و داده زنده باید API واقعی بازار به برنامه متصل شود.
